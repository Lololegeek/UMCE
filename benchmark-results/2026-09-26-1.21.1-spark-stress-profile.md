# UMCE 1.21.1 stress CPU profile

This is a diagnostic profile from the isolated Spark run. It does not compare
baseline and UMCE, and it does not demonstrate an optimization gain.

## Workload and capture

- Minecraft 1.21.1, Fabric Loader 0.16.14, Fabric API 0.116.17, Java 21
- 100 connected protocol clients, 10,081 saved pigs, and 500 saved villagers
- 256 filled hoppers, paired observers, a force-loaded region, and clients
  moving into newly generated chunks
- 60-second Spark CPU sampling window after the 20-second server warm-up
- Spark 1.10.109 used its built-in Java sampler on Windows 11
- The local `.sparkprofile` is at
  `build/benchmark-1.21.1/runs/with-umce-spark3-r1/config/spark/profile-2026-09-26_21.58.11.sparkprofile`
  (SHA-256 `64a940cb51c91c8b58f8db34a72faa5c95e1403535be2084ea4d367f01aaf0`).
  The server saved it locally; it was not uploaded to Spark's viewer.

The profile records 59 server ticks, samples every 4 ms, and contains 20 thread groups. Spark's
metadata reports rolling MSPT mean 87.74 ms and P95 154.91 ms during the run.
These are workload observations, not paired performance results.

## Hot paths visible in the server-thread stacks

1. Movement packet handling: `PlayerMoveC2SPacket.apply` and
   `ServerPlayNetworkHandler.onPlayerMove`, under 100 moving clients.
2. Entity ticks: `EntityList.forEach` → `ServerWorld.tickEntity` →
   `MobEntity.tick` → `AnimalEntity.tickMovement`.
3. Entity tracking and chunk position updates through
   `ServerChunkLoadingManager.tickEntityMovement` and
   `EntityTrackerEntry.sendToOtherNearbyPlayers`.
4. Chunk/entity work and network enqueueing also appear in the tick stacks.

The profile includes packet traffic and entity ticking in the same scenario, so
it cannot attribute all observed time to entity count alone. These stacks are
candidate areas for targeted differential tests; no gameplay patch is enabled
or justified by this profile alone. Create is absent because the tested adapter
targets Fabric while the available Create release for 1.21.1 targets NeoForge.
