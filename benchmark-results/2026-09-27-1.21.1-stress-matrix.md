# UMCE Fabric 1.21.1 stress matrix

Completed: 2026-09-27. Each standard scenario uses Java 21, `-Xms1G -Xmx4G`, a fixed seed and cloned starting world, an alternating baseline/UMCE order, 20 seconds warmup, 30 seconds measured per run, and two paired runs. Both conditions use Fabric API; UMCE is the only mod difference.

The mixed case measured about 120–140 ms/tick in rolling windows on this host, well above the 50 ms target; CPU and memory figures and the paired runs are in its report. Other scenarios also show very wide variation in some extreme workloads. Treat two pairs as descriptive, not as proof of a repeatable performance gain. The 100-TNT pilot is not directly comparable with the standardized cases.

These runs benchmark UMCE's current diagnostics-only Fabric adapter. It records tick timings but ships no gameplay optimization patches, so comparisons show diagnostics overhead and workload behavior, not optimization wins. Create was not included because the 1.21.1 Create target is NeoForge, whereas this harness runs Fabric. The harness does not capture allocation rate, GC pause totals, or network byte counts.
