Captured: 2026-09-26 17:16:17Z

Minecraft 1.21.1, Fabric Loader 0.16.14, Fabric API 0.116.17+1.21.1, Java 21, fixed seed 21072121, normal terrain. Each run starts from an identical saved world. Both conditions include Fabric API and identical 1.21.1 Mineflayer clients; only UMCE differs. No Create factory is included: the available Create release for 1.21.1 targets NeoForge, while this adapter and test target Fabric.
